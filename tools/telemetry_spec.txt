// ets2la_telemetry

// Format:  @struct name | channel prefix | description
//          name | type | unit | binding | description
//   type:     bool u32 s32 u64 s64 f32 f64 str:<length>, or the name of another @struct. "[N]" makes it an array.
//   prefix:   SDK channel name prefix of the struct ("inherit" = the one of the struct that contains it, "empty" = none).
//   binding:  ch:<channel>             SDK channel, relative to the prefix
//             cfg:<id>:<attribute>     SDK configuration attribute ("@" = id of the owning vehicle)
//             ev:<id>:<attribute>      SDK gameplay event attribute
//             present:<id>             true while the configuration <id> is not empty
//             evcount:<id> / evtime:<id>  number of occurrences / in-game time of the gameplay event <id>
//             -                        filled in by the plugin itself (derived value)

# Vec3f
@struct Vec3f | inherit | Three component float vector.
x | f32 |  | - | X component.
y | f32 |  | - | Y component.
z | f32 |  | - | Z component.

# Vec3d
@struct Vec3d | inherit | Three component double vector.
x | f64 |  | - | X component.
y | f64 |  | - | Y component.
z | f64 |  | - | Z component.

# Euler
@struct Euler | inherit | Orientation of an object, every angle is stored in turns (1.0 = 360 degrees), not in degrees or radians.
heading | f32 | turns, [0, 1) | - | Rotation around the vertical axis, counterclockwise seen from above. 0 = north, 0.25 = west, 0.5 = south, 0.75 = east.
pitch | f32 | turns, [-0.25, 0.25] | - | Up/down angle. 0 = horizontal, +0.25 = straight up, -0.25 = straight down.
roll | f32 | turns, [-0.5, 0.5] | - | Rotation around the forward axis, counterclockwise seen in the looking direction.

# PlacementF
@struct PlacementF | inherit | Position and orientation with float precision.
position | Vec3f | m | - | Position.
orientation | Euler |  | - | Orientation.

# PlacementD
@struct PlacementD | inherit | Position and orientation with double precision (needed for world coordinates).
position | Vec3d | m | - | Position.
orientation | Euler |  | - | Orientation.

# Game
@struct Game | empty | State of the game and its clocks.
id | u32 |  | - | Which game loaded the plugin. 0 = unknown, 1 = Euro Truck Simulator 2, 2 = American Truck Simulator.
version_major | u32 |  | - | Major version of the game specific telemetry interface (see scssdk_telemetry_eut2.h / _ats.h).
version_minor | u32 |  | - | Minor version of the game specific telemetry interface. Channels added in newer versions stay 0 on older games.
api_major | u32 |  | - | Major version of the telemetry API the game negotiated with the plugin.
api_minor | u32 |  | - | Minor version of the telemetry API the game negotiated with the plugin.
paused | bool |  | - | True while the game is paused (menu, map, loading). Most channels stop updating then.
config_changes | u32 |  | - | Counter that increases whenever the game sent a configuration event (truck, trailer, job, ... changed). Re-read strings and configuration values when it changes.
timer_restarts | u32 |  | - | Counter that increases whenever the game restarted its timers (for example after loading a save). The three clocks below stay continuous anyway.
render_time_us | u64 | microseconds | - | Continuous clock that drives the visualization, starts at 0 when the plugin loads. Its step follows the rendering frame rate.
simulation_time_us | u64 | microseconds | - | Continuous clock of the physics simulation. Advances in fixed steps, also while the simulation is paused.
paused_simulation_time_us | u64 | microseconds | - | Like simulation_time_us but stops while the physics simulation is paused.
game_time_minutes | u32 | in-game minutes | ch:game.time | Absolute in-game time since 00:00 of the first in-game day. Divide by 1440 for days, modulo 1440 for the time of day.
multiplayer_time_offset_minutes | s32 | in-game minutes | ch:multiplayer.time.offset | Offset from the local game time to the Convoy server time. 0 when multiplayer is not active.
next_rest_stop_minutes | s32 | in-game minutes | ch:rest.stop | Time until the next rest stop is needed (fatigue). Behaviour is game dependent while fatigue simulation is off.
local_scale | f32 |  | ch:local.scale | Scale between real and in-game time/distance of the current map region (1 real second = local_scale in-game seconds). 0 for games with a 1:1 map.

# HShifterSlot
